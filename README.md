# Hi, I'm Görkem ⚡

> Systems-minded engineer chasing **correctness at the lowest levels of the stack.**

I build cycle-faithful emulators of hardware datapaths and hunt IEEE 754 violations
before they reach production AI silicon. If a floating-point edge case exists,
I'll find it — and I'll bring the proof.

---

## 🔬 What I actually do

- **Numerical kernel correctness** — bit-exact emulation of SFPU / SIMD-style datapaths,
  swept against golden references across millions of inputs
- **Low-level debugging** — instruction scheduling, replay buffers, register pressure,
  compiler ICE workarounds on exotic toolchains
- **Proof-driven reporting** — every finding ships with a reproduction table,
  root-cause walkthrough and a strict-improvement validation matrix
